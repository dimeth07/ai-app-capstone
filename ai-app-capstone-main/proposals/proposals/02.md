# Proposal 02

## The problem (one sentence, name a user)
Home buyers want to estimate the fair price of a house based on its size, location, and number of bedrooms.

## Where the data comes from
The public Kaggle "House Prices" dataset (Ames, Iowa). It is free to use and has no licence restrictions.

## A dumb baseline to beat
A baseline that simply predicts the average price of all houses in the dataset. We need to beat this average.

## The biggest risk
The dataset has many text-based categories (like neighborhood names) that need to be converted into numbers, which might be difficult for a beginner.
