# Proposal 03

## The problem (one sentence, name a user)
Office workers waste time manually sorting through hundreds of spam emails every day.

## Where the data comes from
The public SMS Spam Collection dataset from the UCI Machine Learning Repository. It is free to use and has no licence restrictions.

## A dumb baseline to beat
A baseline that simply flags any email containing the word "free" as spam. We need to beat this simple keyword rule.

## The biggest risk
The dataset is quite small, so the model might memorize the emails instead of learning general patterns (overfitting).
