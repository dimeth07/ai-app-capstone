# Proposal 01

## The problem (one sentence, name a user)
Historians want to predict which passengers survived the Titanic based on their ticket and personal details.

## Where the data comes from
The public Kaggle Titanic dataset. It is free to use and has no licence restrictions.

## A dumb baseline to beat
A baseline that simply guesses everyone died. We need to beat this accuracy.

## The biggest risk
The dataset has many missing values in the "Age" column, which could ruin the model.
